# Sales Data ETL Pipeline

This project is a simple ETL pipeline that extracts sales data from a JSON source, transforms and cleans the data using Python and Pandas, and loads the processed data into a database.

## Technologies Used
- Python
- Pandas
- SQL
- Docker

## ETL Process
1. Extract sales data from JSON.
2. Clean and transform the data using Pandas.
3. Load the processed data into SQL.
4. Dockerize the ETL pipeline for easy execution.
